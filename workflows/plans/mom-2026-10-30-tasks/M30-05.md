# M30-05 — Tab sản lượng trong Production Orders

Nguồn: [MoM 30/10 §4]; mã task do TESO đặt.

Trạng thái: **CÓ VIEW THỰC TẾ: lọc PI/công đoạn/liên kết; chưa nhập tay**

## Input

M30-02/03; form nhập tay; fixture Excel; API hiện có.

## Các bước

1. Thiết kế bảng PI → item → công đoạn và nhãn kế hoạch/thực tế.
2. Tạo read API có lọc kỳ, phân trang và trạng thái liên kết.
3. Dùng chung validation cho nhập tay và import.
4. Tách preview với confirm; revalidate snapshot và identity trong transaction.
5. Hiện kết quả từng dòng và bảo toàn provenance.

## Output

tab Sản lượng; API đọc/ghi; import preview/confirm; fixture và kiểm thử

## Tiêu chí xong

Nhập lại không tăng tổng; lỗi không ghi dở ngoài contract; mọi dòng được giải trình; thao tác có kiểm quyền khi phát hành.

## Vùng code/tài liệu cần đọc hoặc thay đổi

src/app/orders/**; src/components/orders/**; src/app/api/**; lib/excel và validations. Đây là phạm vi dự kiến; card triển khai phải ghi file/hàm cụ thể sau thiết kế.

## Thông tin còn thiếu

Identity/replacement ở M30-03; danh mục đơn mới; quyền nhập và xác nhận.

## Kiểm tra và rollback

Phân tích offline: truy vết tới file/sheet/ô, ghi rõ phạm vi chỉ đọc và phần chưa đối soát. Khi thay app: test vùng ảnh hưởng, typecheck và build theo gate repo. Thay DB dùng SQL additive có rollback; chỉ DB local đã xác minh. Giữ dữ liệu nguồn và liên kết cũ. Không QA bằng import production.
