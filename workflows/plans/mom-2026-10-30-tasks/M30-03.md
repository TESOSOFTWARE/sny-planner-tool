# M30-03 — Hợp đồng dữ liệu kế hoạch và thực tế

Nguồn: [MoM 30/10 §4]; mã task do TESO đặt.

Trạng thái: **CODE + MIGRATION LOCAL: tách kế hoạch khỏi actual, nhập tay; đã seed TEST**

## Input

M30-01/02; kế hoạch kéo sợi; báo cáo sản lượng từng công đoạn.

## Các bước

1. Viết một ví dụ đầu-cuối cho mỗi công đoạn.
2. Định nghĩa ngày/ca/máy/PI/item/đơn vị và nguồn.
3. Đề xuất tách bản kế hoạch với số thực tế, lưu revision và tham chiếu nguồn.
4. Chốt identity, phạm vi replacement và xử lý sửa tay sau import.
5. Chốt thiết kế schema/API, rollback trước card thay đổi DB.

## Output

data-contract.md; bảng quyết định nghiệp vụ; sơ đồ quan hệ đề xuất

## Kết quả triển khai local

Thêm `ProductionOutputPlan` và `ManualProductionEntry`; actual nhập tay tách khỏi bảng import công đoạn. API lọc theo công đoạn/ngày và giữ PI nguồn nullable link. Sửa kế hoạch dùng optimistic timestamp, tăng revision và lưu snapshot revision cũ. Migration đã áp trên DB local; script seed tạo mẫu TEST hai lần không tăng số dòng. Chưa có bulk Excel import cho kế hoạch; import actual theo file dùng preview/confirm từng công đoạn ở Reports.

## Tiêu chí xong

Mỗi chỉ tiêu có đơn vị, nguồn có thẩm quyền, khóa và hành vi retry/correction; không tự quy đổi kg sang mét.

## Vùng code/tài liệu cần đọc hoặc thay đổi

prisma/schema.prisma; src/types/**; validations; API sản lượng. Đây là phạm vi dự kiến; card triển khai phải ghi file/hàm cụ thể sau thiết kế.

## Thông tin còn thiếu

Chỉ tiêu tiến độ từng khâu; quấn chỉ tương ứng khâu nào; báo cáo sửa thay thế hay bổ sung.

## Kiểm tra và rollback

Phân tích offline: truy vết tới file/sheet/ô, ghi rõ phạm vi chỉ đọc và phần chưa đối soát. Khi thay app: test vùng ảnh hưởng, typecheck và build theo gate repo. Thay DB dùng SQL additive có rollback; chỉ DB local đã xác minh. Giữ dữ liệu nguồn và liên kết cũ. Không QA bằng import production.
